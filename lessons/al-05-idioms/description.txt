Array Languages, episode 5. An idiom is a short phrase for a pattern that keeps coming back. Each idiom here follows one pattern: the problem, the Rust loop that solves it, the X_eTaL idiom, and what it costs. Running totals are a scan (plus scan, max scan). Adjacent changes shift the list by dropping an item from each end, then subtract or compare. Normalizing takes an aggregate, then extends it to every item (and float, since Int and Float do not mix). Counting occurrences uses unique, an equality table and a reduce, at the cost of a cell for every value and item. Then four more: finding positions with where and index of, membership, moving windows with n wise, and sorting one list by another with grade and select. Every argument and result is drawn as a box, so each shape shows.
