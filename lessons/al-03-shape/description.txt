Array Languages, episode 3. Every array has a shape, a rank and axes. This episode builds up from a scalar to a vector, a matrix and a rank 3 array, and defines rank as a small function. It then works along an axis with the axis written out: reduce, rotate, reverse and transpose, on a matrix and on a rank 3 array, and ravel turns any array back into rank one. Two LeetCode problems (1672, Richest Customer Wealth; 1351, Count Negative Numbers in a Sorted Matrix) are solved in one line each. It ends with tensors in machine learning and on GPUs, and a preview of broadcasting, the topic of the next episode.
