Code is read more often than it is written, so in X_eTaL the way a name looks tells you what it is. A tour of its syntax poster, one panel at a time.

In X_eTaL, an experimental typed array language:
1. An underlined first letter is a function; a name without one is a value
2. A small letter above a name says where it came from: your program, a library, a helper, a macro library
3. An import's alias shows above every name it gives you
4. The arrow binds and equals only compares
5. A function next to a value applies; a quote in front passes the function itself
6. A small number below a function picks its axis: reduce, rotate, transpose
7. A small number above a value is a power; above a function it repeats it (Life to the fourth)
8. Braces make a lambda: alpha on its left, omega on its right, or named arguments
9. A box marks the system: files, input, grids, pictures
10. A question mark between a test and a result is a guard
11. You type it all as ASCII, and it is drawn decorated
12. Square brackets make a train: sum over count is the mean, with no argument named
